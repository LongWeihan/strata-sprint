02 / THE PROFILE

Give the GPU room.
Give the conversation a place.

Upstream Strata already implements these mechanisms. Sprint selects and validates them together for a high-memory, single-GPU workload.

01

Dedicated prompt buffers

8K prefill chunks use their own GPU memory, keeping all target experts resident.

02

Four conversation slots

A 16 GiB host-memory budget preserves exact session state. Short side requests do not fill the slots.

03

Explicit memory headroom

A 16 GiB floor and the real host/container limit control admission and eviction.
